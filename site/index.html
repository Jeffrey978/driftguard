What it can see

The honest version.

A tool that watches your tabs has to be specific about what that means. Nothing here is aspirational — it's what the code does.

Recorded, on your machine, during a session

  • The domain of your active tab
  • The tab's title — switchable off in settings
  • How long the tab was in front of you
  • Prompts you got and how you answered
  • Links you chose to save

Never recorded, in any mode

  • Keystrokes, form fields, passwords
  • Page contents or screenshots
  • Incognito windows — skipped outright
  • Anything at all outside an active session
  • Anything sent anywhere: there is no server

About that install warning

Chrome will tell you DriftGuard can "read and change all your data on all websites." That's real, and it's the honest cost of the product: the prompt has to be able to appear on whatever site you drifted to, and there's no way to know that site in advance. What the permission buys is one overlay on one tab. There is no backend to send anything to — you can confirm that by reading src/background.js, which is in the build you install.

Install

Three minutes, no account.

This is an unpacked developer build, not a Web Store listing yet. That means you can read every line before you run it.

  1. Download the build and unzip it somewhere you'll keep it.
  2. Open chrome://extensions and switch on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Pin DriftGuard so the icon is one click away.
  5. Open the work you're avoiding, type what you're meant to be doing, and start.
